
# Pediatric Sepsis Prediction

A data science project focused on predicting pediatric sepsis risk to support early identification of children who may require timely clinical attention.

## Objectives
- Analyze clinical data to identify patterns associated with pediatric sepsis.
- Develop and evaluate machine learning models for risk prediction.
- Explore how predictive analytics can support early risk identification and clinical decision-making.

## Methodology
- Data preprocessing and exploratory data analysis
- Feature engineering and selection
- Machine learning model development
- Model evaluation and performance comparison

## Tech Stack
- Python
- Pandas and NumPy
- Scikit-learn
- Matplotlib and Seaborn

## Getting Started

Clone the repository:

```bash
git clone https://github.com/ibtj21/TI_Analytical_Pediatric_Sepsis.git
cd TI_Analytical_Pediatric_Sepsis
```

Install the required dependencies according to the project environment, then run the notebook or scripts provided in the repository.

## Intended Impact

The project explores the use of data-driven methods to support earlier recognition of pediatric sepsis risk. It is an analytical project, not a clinically validated diagnostic tool.
